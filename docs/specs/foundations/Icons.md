## Material Symbols — render configuration

Use this configuration for every Material Symbols icon, so that what renders in
the app matches what the designer placed.

| Setting | Value |
|---|---|
| Style | **Rounded** |
| Icon size / optical size | **24px** |
| Fill | **0** (unless mentioned otherwise) |
| Weight | **300** |
| Grade | **0** |

**Any deviation from this configuration is stated explicitly** at the point of use
— in the component file or on the screen. Where nothing is stated, the
configuration above holds.
